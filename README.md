# Комплименты на стенах

`wall_compliments.py` оставляет от имени Иишнова небольшой комплимент на стене
каждого признанного им пользователя. Успешные отправки сохраняются локально,
поэтому при повторных запусках один человек не получит второе сообщение.

## Запуск

1. Создайте `recognized.json` с числовыми ID пользователей:

   ```json
   [759, 812, 945]
   ```

2. Передайте актуальный токен только через окружение и запустите программу:

   ```bash
   EGOROD_TOKEN='...' python3 wall_compliments.py recognized.json
   ```

По умолчанию история хранится в `.wall-compliments-sent.json`, а между запросами
выдерживается 21 секунда, чтобы соблюдать лимит API в три запроса в минуту.
Пути и интервал можно изменить параметрами `--state` и `--interval`.

Токен из журналов браузера нельзя добавлять в репозиторий. Если он был раскрыт,
его следует отозвать и выпустить заново.
